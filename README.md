# Техническая спецификация игры "Kernel"
## 1. Общее описание системы
### 1.1 Назначение системы
Название: Kernel
Жанр: приключенческий экшен с элементами паркура, головоломок и шутера
Целевая платформа: настольные ПК
Количество разработчиков: 3
Камера: от третьего лица
Режим: одиночный, полностью офлайн
Ориентировочная продолжительность: 30-50 минут
Движок: Unity
Язык: С#
### 1.2 Описание концепции
Игрок управляет робот - антивирусом, который существует внутри зараженной системы.
Робот-антивирус пробирается через заражённое ядро системы, его цель - освободить свою напарницу, которую похитил вирус - босс.
Робот проходит такие испытания как паркур по разрушенным платформам, нахождение ловушек, логическая головоломка с уравнениями, головоломка с подъемом на уровень выше, стрельба по вирусам, сбор шестеренок, поиск ключей - доступов, финальный бой с пауком (главным врагом).
В ходе игры робот может использовать магнитные перчатки для перемещения (притягивание к железным платформам), бластер для сражения с врагами
После победы над боссом игрок освобождает подругу, зараженная система начинает очищаться. Игра считается пройденной
### 1.3 Целевая аудитория
Аудитория 12-25 лет знакомые с 3D-платформерами и шутерами от третьего лица
### 1.4 Дизайн-принципы
П-1. Одна итерация — одна механика. Каждый новый фрагмент уровня вводит ровно одну новую механику либо комбинирует две уже освоенные.
П-2. Отсутствие отдельных обучающих сцен. Механика объясняется контекстной подсказкой непосредственно перед местом её обязательного применения.
П-3. Прогресс всегда виден. У любой блокировки прохождения есть визуальный индикатор состояния (счётчик, подсвеченная кнопка, закрытая дверь).
П-4. Из любой точки можно вернуться назад. Уровень не должен допускать состояний, из которых прохождение невозможно.
## Глоссарий
Кайл - 	Игровой персонаж, робот-антивирус
Напарница - НПС персонаж, заперт в клетке. Условие победы - его освобождение
Паук - финальный противник, вирус
Бит - 	Единица здоровья персонажа. На интерфейсе отображается сердцами.
Слизь - зона на полу, наносящая урон игроку при контакте
Магнитный блок -   	Объект золотого цвета, к которому персонаж может притянуться перчаткой.
Магнитная перчатка - 	Стартовый предмет инвентаря, инструмент перемещения.
Бластер - Оружие дальнего боя, подбираемый предмет инвентаря.
Арена - 	Огороженная область уровня, вход в которую запускает боевое столкновение.
Панель управления - переключаемый элемент конопочной головоломки
## Границы проекта
### Должно входить в объем
Один сквозной уровень длительностью 20–40 минут.
Передвижение от третьего лица: ходьба, спринт, прыжок, подъём по лестницам, перемещение по блокам.
Три инструментальные механики: стрельба, магнитное притяжение, перетаскивание физических блоков.
Три типа блокировок прогресса: сбор предметов, логическая головоломка, боевая арена.
Один тип рядового противника, зоны урона, один босс с состояниями поведения.
Интерфейс: здоровье, счётчик прогресса, инвентарь, подсказки, стартовый и финальный экраны.
### Допущения
Д-1. В сцене присутствует ровно один управляемый персонаж и один экземпляр инвентаря.
Д-2. Игрок использует клавиатуру и мышь; минимальное разрешение экрана 1280×720.
Д-3. Продолжительность одного сеанса позволяет пройти уровень целиком; сохранение между сеансами не требуется.
Д-4. Все игровые данные хранятся в ресурсах проекта; внешние конфигурационные файлы и база данных не используются.
